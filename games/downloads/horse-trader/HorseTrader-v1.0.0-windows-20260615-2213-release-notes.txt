HorseTrader v1.0.0 Windows build 20260615-2213

Public desktop multiplayer updater fix build.

Changes:
- Fixed the updater so it does not try to overwrite the currently running Play HorseTrader launcher.
- The updater now skips locked launcher files and updates the game files beneath them.
- The launcher now shows an update failure message instead of hiding updater failures.
- Kept the room-first multiplayer join flow from build 20260615-2132.
- Kept the LAN-capable server binding from build 20260615-2132.
- Kept latest.zip matched to this build.

Important note:
- Builds older than this one may not auto-update reliably because their updater can fail while copying the running launcher.
- If a player is still on an older build and update does not happen, download latest.zip once. Builds from 20260615-2213 onward have the safer updater.

Tested:
- Python compile check.
- Server smoke test.
- Desktop multiplayer smoke test.
- AI scenario tests.
- Build-script test gate before packaging.
- Folder-wrapped ZIP layout.
